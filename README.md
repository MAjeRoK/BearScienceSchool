# BearScienceSchool (Формула Спасения)
Проект на геймджем Акселератора полезных игр от команды Peekaboo

Игра про строительство базы и добычу необычных минералов, похожа по структуре на простой кликкер

## Установка игры:
Скачать архив `.zip` с вкладки релизов репозитория. Распаковать в удобное место и запустить `.exe` файл

## Удаление игры:
Удалить распакованную папку, удалить папку сохранений по пути `C:\Users\<имя пользователя>\AppData\Local\BearScienceSchool`
